# Task 2: Pivot Tables & Pivot Charts

## Objective
- Create and modify Pivot Tables with multiple fields.
- Use Calculated Fields for custom calculations.
- Implement Slicers & Timelines for interactive filtering.
- Build Pivot Charts to visualize key metrics

---

## Data Preparation & Excel Techniques

1. The analysis focused on social media engagement across three major platforms: Facebook, Instagram, and Twitter.
2. Before creating the dashboard, I reviewed the dataset and ensured that the relevant fields were properly structured for Pivot Table analysis and visualization.
3. I also addressed date formatting to ensure that monthly trends were displayed in the correct chronological order.
---

## Pivot Tables

I created and modified Pivot Tables using multiple fields to summarize social media engagement across different dimensions.

The Pivot Tables were used to examine:

* Engagement distribution across platforms
* Audience sentiment and emotional reactions
* Post volume by country
* Monthly engagement trends

---

## Calculated Fields

I used calculated fields to create custom calculations from the available dataset fields.

---

## Slicers & Timeline

I implemented **Slicers** to provide interactive filtering across key dimensions of the dashboard.

The dashboard allows users to filter the analysis based on relevant fields such as:

* Platform
* Sentiment
* Country

I also implemented a timeline to allow users to explore engagement trends across different periods.

These interactive controls allow users to change the dashboard view without modifying the underlying Pivot Tables.

---

## Pivot Charts

I created pivot charts to visually communicate the results generated from the Pivot Tables.

The dashboard visualizes:

* Platform reach and distribution
* Sentiment breakdown
* Geographical post volume
* Monthly engagement trends

The combination of pivot tables, pivot charts, slicers and timeline transformed the analysis into an interactive dashboard for exploring social media performance.

---

### Challenge

During dashboard development, I encountered a data-formatting challenge when numeric months were converted into text. This caused incorrect sorting on the time-series visualization.

I resolved the issue by restructuring the month field using appropriate data formatting, allowing the timeline to display months in the correct chronological order.

---

## Interactive Dashboard

The completed dashboard combines pivot tables, calculated fields, slicers, timeline and pivot charts into a single interactive view.

Users can filter the dashboard and explore how engagement varies across platforms, sentiments, countries and time periods.

---

## Key Outcome

This project demonstrated how excel's pivot table and dashboard features can transform raw social media engagement data into an interactive analytical tool.

Rather than manually reviewing individual records, I used Pivot Tables and Pivot Charts to summarize key metrics, while Slicers and Timeline provided an interactive way to explore the results.

The project also reinforced the importance of data formatting and modeling. A visually appealing dashboard is only useful when the underlying data is structured correctly and the resulting visualizations accurately represent the trends.
